### 🔨 What I'm building

**[clipcode](https://github.com/Yash-Matariya/clipcode)** — a shared code editor.
Open a room, send someone the code, and you both type in the same document.

Spring Boot over WebSocket/STOMP. Edits are range replacements that carry the
version they were based on, and the server applies one only if that version still
matches — so a stale offset can never be applied and the document cannot be left
corrupted. It is last-write-wins rather than a CRDT, which is a trade I can explain
rather than one I am hiding.

**[albion-refine-advisor](https://github.com/Yash-Matariya/albion-refine-advisor)** —
a profit advisor for a game economy, built on a crowdsourced market API.

Spring Boot, PostgreSQL, Flyway, scheduled ingestion. Most of the work went into the
opposite of what I set out to do: measuring that the bid-ask spread (9–23%) was the
same size as the margin I was hunting (1–40%), and then making the tool **refuse to
answer** unless every input price is fresh — rather than return a confident number
that would cost someone real money.
